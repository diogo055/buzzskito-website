## The key finding
**No bug bomb is registered for home use in Canada.** Health Canada's re-evaluation decision on pyrethrins
(RVD2023-06, March 2, 2023) cancelled "Domestic-class pressurized product application using total release foggers
(including lock-valve mechanism)" and "Domestic handler applications using handheld and stationary foggers" ("since
health risks or value were not shown to be acceptable"). Its factsheet sets the last date of sale for the cancelled
domestic products at March 2, 2024 and the last date of use at September 2, 2024. The registry lists Doktor Doom Total
Release Fogger II (33939), Go Green Doktor Doom Total Release Fogger (28912), Konk Complete Release Fogger (32676) and
Knockdown Total Release Fumigator-Water Based (34692) as historical with exactly those dates; Raid Fumigator (25167,
permethrin) ended in 2021. Searches for registered domestic products named fogger / total release / fumigator / bomb
return only outdoor products. Konk 403 Total Release Fumigator (27678) is still registered, commercial class only, and
does not list bed bugs.
